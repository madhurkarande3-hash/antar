# 3D Pod Explorer

The `pod/index.html` file is the interactive physical-form-factor concept for ANTAR.

It is intentionally separate from the road-detection simulator:

- `simulation/antar-sim.html` demonstrates the **detection logic** and three scenarios.
- `pod/index.html` demonstrates the **physical pod concept**, enclosure, sensors, ESP32 electronics, wiring, antenna, and transmission visualization.

Open either HTML file directly in a modern browser.
